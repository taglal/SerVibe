# SerVibe
A ServiBe webszolgáltatás Hujber Enzó Meliton és Horváth Dániel Gábor, a Bajai SZC Türr István Technikum 13.A osztályos szoftverfejlesztő tanulóinak közös projektje. A rendszer célja egy korszerű, felhasználóbarát platform létrehozása, amely megkönnyíti a megbízható szakemberek keresését, az ajánlatkérést és az időpontfoglalást.
